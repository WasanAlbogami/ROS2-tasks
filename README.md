# ROS 2 Tasks

This repository contains two ROS 2 tasks:

## 1. Publisher and Subscriber

A ROS 2 Publisher and Subscriber were implemented to communicate using a topic.

The Publisher sends a message other than the default "Hello World" message, and the Subscriber receives and displays the published message.

## 2. Turtle Robot - Square Movement

A TurtleSim robot was programmed to move in a square path.

The turtle moves forward and turns 90 degrees at each corner until it completes a square.

## Requirements

- Ubuntu 22.04
- ROS 2 Humble
- Python 3
- Turtlesim

## Result

Both tasks demonstrate basic ROS 2 communication and robot movement using Turtlesim.
